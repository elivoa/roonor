# Roon Monitor

一个小巧的 macOS 桌面 Roon 插件原型：透明悬浮窗、桌面宠物入口、当前播放信息、专辑名称、封面、播放控制，以及 SQLite 播放快照存储。

点击左侧当前封面可打开 `Roon Arts` 媒体窗口。该窗口只显示当前专辑的封面及为当前专辑添加的本地图片和 PDF；支持横向滑动浏览、双击通过 macOS 打开原文件，并自动记住窗口位置和尺寸。

## 运行

```sh
npm install
npm start
```

第一次运行后，需要到 Roon 的 `Settings -> Extensions` 里启用 `Roon Monitor Mascot`。

Roon Server 默认按 `192.168.11.100` 展示连接目标。Roon API 的 WebSocket 端口由 Roon 动态广播，应用会使用官方 discovery 机制寻找并配对 Core；Roon 配对状态会持久化到本地 SQLite，重新打开桌面程序后无需依赖启动目录中的临时配置文件。

若窗口显示“已发现 Roon Server，扩展 API 连接失败，正在重试”，表示 Core 已回应 discovery，但它动态广播出的扩展 API TCP 端口当前从本机不可达；程序会持续重新发现并尝试注册。

## 桌面歌词

主窗口中的“词”按钮用于显示或隐藏独立歌词悬浮窗。歌词窗为透明背景，可单独拖动、调整尺寸并记住位置；匹配到带时间戳的歌词后会随 Roon 播放进度同步切换当前行。由于 Roon Transport API 不直接提供歌词，程序会用当前歌曲的曲名、歌手、专辑与时长向 `LRCLIB` 查询歌词，并将结果缓存在本地 SQLite 数据库中。

## 实时频谱

右侧频谱视图使用 Spek 风格坐标与 `-100 dB` 到 `-20 dB` 色标，只绘制已捕获到的音频时间段。应用会选择 `BlackHole` 或本机已有的 `Background Music` 回环输入；首次开始播放时会请求麦克风/音频输入权限。要显示真实频谱，Roon 的实际播放音频必须在这台 Mac 上经过所选回环设备。采集后的频谱会按歌曲与时间位置量化保存在 SQLite 中，下次播放同一首歌时可恢复已经绘制的区段并继续补画。

点击左侧专辑封面小窗会打开当前专辑的 arts 浏览窗口；点击中间信息小窗会打开播放详情；点击右侧频谱小窗会让同一个可调整尺寸的大窗口显示实时频谱。大窗口的位置和尺寸会持久化到 SQLite，并在重新打开时恢复。已成功取得的 Roon 封面会缓存到本地并在下次播放时立即恢复；若 Roon 当前图片接口超时或报错，应用会尝试从公开专辑目录取得同专辑封面并写入相同缓存。

Roon Transport 播放状态仅提供一张当前播放封面的 `image_key`，没有提供同一专辑的多张 booklet/arts 列表；因此自动同步目前只能取得主封面。Arts 窗口仍支持为当前专辑导入多张图片或 PDF。
